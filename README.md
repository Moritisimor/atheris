# atheris
Python program for graphing/plotting functions using turtle

## Usage
You will need python, preferably the latest version.

You will also need the turtle and tk module installed. Most of the time they are already installed.

Clone the repo and run it with python:
```bash
git clone https://github.com/Moritisimor/atheris
cd atheris
python atheris.py
```

The function term field allows for arbitrary python functions.

There are also a few functions that come from the math module:
- sin
- cos
- tan
- sqrt

You also have full access to the math module.

### Function examples
The linear function:
```python
lambda x: x
```

The quadratic function:
```python
lambda x: x ** 2
```

The cubic function:
```python
lambda x: x ** 3
```

Sine wave:
```python
lambda x: sin(x)
```
